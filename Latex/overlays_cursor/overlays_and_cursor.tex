\subsection{The Cursor System}
\textcolor{commentGreen}{*** WIP ***}

Select a cursor mode from the toolbar before clicking on the waterfall:

\begin{compactitem}
\item \textbf{Single:} Places one frequency marker at the clicked frequency $f$.
\item \textbf{Harmonic:} Places harmonic series line starting from the fundamental + N harmonics above it. Configurable N and line width.
\item \textbf{Resonance:} Adds resonance lines on both sides of $f$ using the specified spacing $\Delta$ and line count N. "Right only" shows only lines to the right of $f$ (upper sideband).
\end{compactitem}
